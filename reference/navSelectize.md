# Create a special `selectize` input in the navigation bar

Create a special `selectize` input in the navigation bar

## Usage

``` r
navSelectize(id, label, placeholder = label, ASevent = FALSE)
```

## Arguments

- id:

  Character: input identifier

- label:

  Character: input label

- placeholder:

  Character: input placeholder

- ASevent:

  Boolean: select alternative splicing events?

## Value

HTML element to be included in a navigation bar
