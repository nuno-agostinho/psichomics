# Shiny wrapper to load GTEx data

Shiny wrapper to load GTEx data

## Usage

``` r
loadGtexDataShiny(session, input, replace = TRUE)
```

## Arguments

- session:

  Shiny session

- input:

  Shiny input

- replace:

  Boolean: replace loaded data?

## Value

`NULL` (function is only used to modify the Shiny session's state or
internal variables)
