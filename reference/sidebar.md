# Sidebar without a well

Modified version of
[`shiny::sidebarPanel`](https://rdrr.io/pkg/shiny/man/sidebarLayout.html)
without a well

## Usage

``` r
sidebar(..., width = 4)
```

## Arguments

- ...:

  Output elements to include in the sidebar/main panel.

- width:

  The width of the sidebar and main panel. By default, the sidebar takes
  up 1/3 of the width, and the main panel 2/3. The total width must be
  12 or less.

## Value

HTML elements
