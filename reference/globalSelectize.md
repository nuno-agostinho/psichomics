# Create a `selectize` input available from any page

Create a `selectize` input available from any page

## Usage

``` r
globalSelectize(id, placeholder, ASevent = FALSE)
```

## Arguments

- id:

  Character: input identifier

- placeholder:

  Character: input placeholder

- ASevent:

  Boolean: select alternative splicing events?

## Value

HTML element for a global `selectize` input
