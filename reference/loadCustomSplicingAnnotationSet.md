# Set of functions to load a custom alternative splicing annotation

Instructions to build the Shiny app

## Usage

``` r
loadCustomSplicingAnnotationSet(session, input, output)
```

## Arguments

- session:

  Shiny session

- input:

  Shiny input

- output:

  Shiny output

## Value

`NULL` (function is only used to modify the Shiny session's state or
internal variables)
