# Data grouping interface

Data grouping interface

## Usage

``` r
groupByAttribute(ns, cols, id, example)

groupByPreMadeList(ns, data, id)

groupById(ns, id)

groupByExpression(ns, id)

groupByGrep(ns, cols, id)
```

## Arguments

- ns:

  Namespace function

- cols:

  Character or list: name of columns to show

- id:

  Character: identifier

- example:

  Character: text to show as an example

- data:

  List: list of groups with elements

## Value

HTML elements
