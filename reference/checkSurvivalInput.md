# Prepare survival terms in case of valid input

Prepare survival terms in case of valid input

## Usage

``` r
checkSurvivalInput(session, input, coxph = FALSE)
```

## Arguments

- session:

  Shiny session

- input:

  Shiny input

- coxph:

  Boolean: prepare data for Cox models?

## Value

`NULL` (function is only used to modify the Shiny session's state or
internal variables)
